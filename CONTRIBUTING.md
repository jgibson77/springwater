# Contributing to Springwater

**Springwater Core v1.0 is frozen.** The seven rules will never change.

## What You Can Contribute

- **Schemas** — New document types (poetry, legal, academic, recipes)
- **Tools** — Validators, renderers, editors, syntax highlighters
- **Examples** — Real documents demonstrating the format
- **Documentation** — Tutorials, translations, guides

## What You Cannot Change

- Core syntax (frozen)
- The seven rules
- Tag character (^)
- Published schema versions

## Schema Guidelines

1. Validate against `schema.schema.springwater`
2. Match domain conventions (see docs/DESIGN_NOTE_METADATA.txt)
3. Include valid and invalid examples
4. Use absolute validation (no warnings)

## Pull Requests

1. Fork, branch, commit, push, PR
2. All schemas must validate
3. All tests must pass
4. Documentation required
